# React + Vite + TailwindCSS Starter Template

We will use this repository as a template for the UI projects we will be building in [this repository](https://github.com/sankthomas/ui-design-components). At the time of writing this, the latest project is the Cookie Preference Modal, and soon I will start using TypeScript to build the projects.

We will be using this repo to create every new application that we need to build because in it, I have installed Tailwind CSS, I have added the Geist custom font to the `index.css` file, and I have also installed `lucide-react` in case a project will require some icons.

I have deleted any lock files in order to ensure that anyone who uses this repository will use their preferred package manager, and there won't be any conflicts in the files.

That's all for now.
